# 💡 What is IdeaShorts?

**IdeaShorts is a platform for founders, innovators, and builders to showcase ideas, receive feedback, connect with other builders, and build in public.**

The vision is simple:

> **Give ideas a place to be seen, challenged, improved, and built.**

IdeaShorts is being built around the journey from:

**Idea → Feedback → People → Building → Growth**

We're currently building **V1** and turning the concept into a real product.
